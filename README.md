# Milan & Lisa — Engagement Invitation

A static, mobile-first engagement invitation website.

## Files
- `index.html` — invitation content
- `style.css` — elegant floral styling
- `script.js` — subtle reveal animations
- `images/` — add your photos here

## RSVP
The form is ready for Formspree, but the placeholder endpoint must be replaced:
`https://formspree.io/f/YOUR_FORM_ID`

Create a free Formspree form, then replace `YOUR_FORM_ID` in `index.html`.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files in this folder.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. GitHub will provide the public invitation URL.

## Photos
Put your photos in `images/` and replace the placeholder photo backgrounds in `style.css` with URLs such as:
`background-image: url('images/photo-1.jpg');`
